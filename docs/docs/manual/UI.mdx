title: Spatial UI
---

XR Blocks includes one built-in spatial UI system. It uses flex layout and
supports world-space cards, view-space overlays, text, images, icons, buttons,
and sliders.

The renderer starts with XR Blocks. Applications do not need to register a
separate UI addon.

## World-space cards

Use [`UICard`](/api/classes/UICard) as the root of a UI tree. Its `size` is in
meters. Child layout values use the UIKit layout coordinate system.

```js
import * as xb from 'xrblocks';

const card = new xb.UICard({
  size: {width: 0.6, height: 0.35},
  manipulation: true,
  edge: {scale: true},
  style: {
    flexDirection: 'column',
    gap: 16,
    padding: 24,
    backgroundColor: '#202124',
    borderRadius: 24,
  },
});
card.position.set(0, 1.4, -1);

card.add(
  new xb.UIText({
    text: 'Welcome',
    style: {fontSize: 32, color: '#ffffff'},
  }),
  new xb.UIButton({
    label: 'Continue',
    onClick: () => console.log('Continue'),
    style: {padding: 16, backgroundColor: '#4285f4'},
  })
);

xb.add(card);
xb.init(new xb.Options());
```

Set `manipulation: true` to let the user move and scale a card. Set `edge` to
show its manipulation surface.

## View-space overlays

Use [`UIOverlay`](/api/classes/UIOverlay) for content fixed to the view. Its
world transform does not affect rendering.

```js
const overlay = new xb.UIOverlay({
  style: {
    flexDirection: 'row',
    justifyContent: 'center',
    padding: 24,
  },
});

overlay.add(
  new xb.UIText({
    text: 'Ready',
    style: {fontSize: 24, color: '#ffffff'},
  })
);

xb.add(overlay);
```

## Components

- `UIPanel`: passive layout and visual grouping
- `UIText`: text content
- `UIImage`: URL-backed or texture-backed image
- `UIIcon`: Material Symbol icon
- `UIButton`: accessible button with `onClick`
- `UISlider`: horizontal value input
- `ModelViewer`: model display and manipulation surface

Every UI component and public UI type is exported from `xrblocks`.
