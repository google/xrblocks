XR Blocks includes one built-in spatial UI system. It uses flex layout and
supports world-space cards, view-space overlays, text, images, icons, buttons,
and sliders.

The renderer starts with XR Blocks. Applications do not need to register a
separate UI addon.

## World-space cards

Use [`UICard`](/api/classes/UICard) as the root of a UI tree. Its `size` is in
meters. Child layout values use the UIKit layout coordinate system. Cards use
the theme's `surface` appearance by default.

```js
import * as xb from 'xrblocks';

const card = new xb.UICard({
  size: {width: 0.6, height: 0.35},
  manipulation: true,
  edge: {scale: true},
  style: {
    flexDirection: 'column',
    gap: 16,
    padding: 24,
    backgroundColor: '#202124',
    borderRadius: 24,
  },
});
card.position.set(0, 1.4, -1);

card.add(
  new xb.UIText({
    text: 'Welcome',
    style: {fontSize: 32, color: '#ffffff'},
  }),
  new xb.UIButton({
    label: 'Continue',
    onClick: () => console.log('Continue'),
    style: {padding: 16, backgroundColor: '#4285f4'},
  })
);

xb.add(card);
xb.init(new xb.Options());
```

Set `manipulation: true` to enable the default card movement and scale actions. Set
`edge` to show the enabled actions. The edge does not enable actions that are absent from
the manipulation configuration.

## View-space overlays

Use [`UIOverlay`](/api/classes/UIOverlay) for content fixed to the view. Its
world transform does not affect rendering. An overlay is a bounded themed
surface positioned inside a private full-viewport layout container.

```js
const overlay = new xb.UIOverlay({
  style: {
    width: 360,
    position: 'absolute',
    left: '50%',
    bottom: 24,
    transform: {translateX: '-50%'},
  },
  children: [new xb.UIText({text: 'Ready', style: {fontSize: 24}})],
});

xb.add(overlay);
```

Set `appearance: 'none'` on a card or overlay when it must be a transparent
layout root. The default `appearance: 'surface'` applies
`theme.styles.surface`. `UIPanel` remains a neutral nested layout element.

## Validate layout

After the UI renderer completes a frame, validate one mounted root or every
mounted root:

```js
const report = xb.ui.validate(overlay);
if (!report.ok) console.table(report.issues);
```

The report identifies invalid layout, overflowing content, clipped text, and
overlay surfaces outside the viewport. `ready` is false when no completed
mounted layout is available.

## Components

- `UIPanel`: passive layout and visual grouping
- `UIText`: text content
- `UIImage`: URL-backed or texture-backed image
- `UIIcon`: Material Symbol icon
- `UIButton`: accessible button with `onClick`
- `UISlider`: horizontal value input
- `ModelViewer`: model display and manipulation surface

Every UI component and public UI type is exported from `xrblocks`.

## Controls and direct updates

Use semantic controls instead of attaching raw pointer listeners to panels:

```js
const status = new xb.UIText({text: 'Ready'});
const slider = new xb.UISlider({
  ariaLabel: 'Volume',
  min: 0,
  max: 1,
  step: 0.05,
  value: 0.5,
  onInput: (value) => (status.text = `Volume ${value}`),
  onChange: (value) => saveVolume(value),
});
```

`onInput` reports live captured changes. `onChange` reports one completed changed
interaction. A canceled slider interaction restores its starting value.

Update component properties directly. Nested style and size changes are observed:

```js
status.text = 'Complete';
button.disabled = true;
button.style.backgroundColor = 'rgba(66, 133, 244, 0.7)';
card.size.width = 0.72;
```

A `UIButton` with custom children must have an `ariaLabel`. Do not combine custom button
children with the `label` or `icon` convenience fields.

## Themes and appearance

Set the global theme by preset name or provide a theme update:

```js
xb.ui.theme = 'grayGlass';
// Other built-in preset: 'colorful'
```

Cards and overlays use the theme `surface` appearance by default. Use
`appearance: 'none'` for a transparent layout root. `UIPanel` has no root appearance.

## Text layout

`UIText` automatically uses a system-font canvas when its content contains
glyphs that are not available in UIkit's default atlas. The mounted layout
node stays stable when dynamic text changes between native and Unicode
rendering.

Use `whiteSpace: 'pre-line'` to preserve explicit line breaks. A fixed-height
text viewport can keep its newest lines visible by combining bottom alignment
with clipped overflow:

```js
const transcript = new xb.UIText({
  text: 'You: Hello\n\nGemini: 你好',
  style: {
    width: '100%',
    height: 240,
    whiteSpace: 'pre-line',
    verticalAlign: 'bottom',
    overflow: 'hidden',
  },
});
```

updates, and theme switching.
