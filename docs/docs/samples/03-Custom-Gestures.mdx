This sample uses the gesture pipeline with a custom `GestureRecognizer` and
shows the live results in a spatial `UICard`. The recognizer receives
`HandContext`, builds bone-angle features with `getRelativeBoneAngles(context)`,
and returns string gesture names with confidence scores.
