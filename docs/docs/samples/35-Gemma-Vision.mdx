## What am I looking at?

Capture the camera view, then ask an on-device vision model to describe it or read visible text. Choose **Gemma 4 E2B** for the best quality and translation to English, or **Lite** (SmolVLM2 500M) for phones and headsets with less memory. Typed follow-ups refer to the same frozen image. Image understanding and text generation run entirely on-device in a WebGPU worker, without an API key or cloud inference.

Use Chrome with WebGPU. Pick a model on the 2D page or the spatial card and press **Download Gemma 4 (~3.4 GB)** or **Download Lite (~360 MB)**, then choose **Continue in simulator** or enter XR. Each model is saved in the browser cache for later visits, and you can switch between cached models, even offline.

Camera frames come from `deviceCamera.captureSnapshot({outputFormat: 'imageData', width, height})`. The worker uses Transformers.js 4.3.0 with pinned Gemma 4 E2B and SmolVLM2 500M ONNX models, and loads one model at a time. A single retained transcript text node receives batched updates rather than rebuilding the card for each streamed chunk.

Camera images, questions, and answers stay on the device. Initial application, runtime, and model downloads use the network; subsequent questions work offline while the model remains loaded. See the [README device notes](https://github.com/google/xrblocks/tree/main/demos/gemma_vision#device-notes) for tested hardware and startup measurements.
