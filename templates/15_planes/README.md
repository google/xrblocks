# Planes

Detect physical planes, visualize their wireframes, and place an object on a
horizontal surface.

## Run

Serve the repository and open `/templates/15_planes/`, then enter XR or use the
desktop simulator.

## Controls

Look around the room while the template searches for a horizontal plane (such
as a table or floor) for up to 15 seconds. Detected plane outlines are shown in
yellow.
