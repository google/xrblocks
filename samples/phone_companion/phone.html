Pair with your headset

  1. Find the 4-character pairing code in the headset.
  2. Enter the pairing code below.
  3. Check the number on both screens, then choose Accept phone in the headset.

Paired before? Choose Pair a different phone in the headset for a new pairing code.

Disconnect this phone?

This ends this phone session. To pair again, choose Pair a different phone in the headset.
